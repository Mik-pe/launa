# Balboa BP6013G1 Controller

## Overview

The BP6013G1 is a Balboa Water Group spa controller from the BP series. It is
the main controller used in this project.

## Key Specifications

- **Series**: BP (Balboa Premium)
- **Protocol**: RS-485 serial bus, 115200 baud, 8N1
- **WiFi Module**: BWGWiFi1 (optional, connects via same RS-485 bus)
- **Display Compatibility**: TP600, TP800, TP900 topside panels
- **Voltage**: 240V / 60Hz (North America) or 230V / 50Hz (EU)
- **Heater**: Integrated, typically 4.0kW

## Connectivity

The BP6013G1 exposes an RS-485 bus that all topside panels and the optional WiFi
module connect to. Our ESP32 will tap into this bus via an RS-485 transceiver
(e.g., MAX485 or SP3485).

### Pin Reference (RS-485 connector)

The controller typically has a 4-pin or 8-pin connector for the topside panel /
WiFi module. The RS-485 data lines are on this connector:

| Pin | Function |
|-----|----------|
| 1 | RS-485 Data+ (A) |
| 2 | RS-485 Data- (B) |
| 3 | Not connected / future |
| 4 | Ground |

> **Note**: Verify pin assignments for your specific wiring harness. The
> BP6013G1 may ship with different connector configurations depending on the
> spa manufacturer.

## Typical Configuration

For a BP6013G1, the configuration response typically indicates:

- 2 two-speed pumps (or 1 two-speed + 1 single-speed)
- 1 circulation pump
- 1 light
- 1 blower (optional)
- Heater voltage: 240V
- Temperature range: Fahrenheit or Celsius (configurable)

## Communication Approach

We connect the ESP32 directly to the RS-485 bus (same bus the topside panel and
WiFi module use). The ESP32 acts as an additional client on the bus:

1. **Listen** for status updates broadcast every ~1 second
2. **Register** as a client using the ID assignment protocol
3. **Parse** status updates to extract temperature, pump state, etc.
4. **Publish** parsed data to Home Assistant via MQTT over WiFi
5. **Accept** commands from Home Assistant and forward them to the spa controller

## Hardware Requirements

- ESP32-C3 or ESP32-S3 development board
- RS-485 transceiver module (MAX485, SP3485, or similar)
- 3.3V ↔ 5V logic level shifter (if needed, some RS-485 modules work at 3.3V)
- Jumper wires for connecting to the spa's RS-485 bus

## Wiring Diagram

```
ESP32                RS-485 Transceiver         Spa Controller
──────               ──────────────────         ─────────────
GPIO TX (UART) ────► DI (Data In)
GPIO RX (UART) ◄──── RO (Data Out)
GPIO DIR       ────► DE/RE (Direction)
3.3V           ────► VCC
GND            ────► GND
                      A ──────────────────────► RS-485 Data+
                      B ──────────────────────► RS-485 Data-
```

> **Warning**: Always power off the spa controller before making wiring changes.
> The RS-485 bus is galvanically isolated in most installations but verify
> before connecting.
